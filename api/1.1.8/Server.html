serviceDeep​

Server.serviceDeep(
folder: Instance--

The instance containing the service modules

) → ()

Constructs all services out of the modules in the descendants in the given instance. If the parent of a service module has an "@load" module, it will use it to check whether it should load any service modules in that folder.
