controllerDeep​

Client.controllerDeep(
folder: Instance--

The instance containing the controller modules

) → ()

Constructs all controllers out of the modules in the children in the given instance. If the parent of a controller module has an "@load" module, it will use it to check whether it should load any controller modules in that folder.
