### What's fish?
fish is an **experiential** (*involving or based on experience and observation*) typed framework for Roblox intended to make writing and developing games easier than ever before. With structure inspired from [Knit](https://github.com/Sleitnick/Knit) (Services & Controllers) and **full type support**, knowing how your code is structured and functions allows you to focus on creating what you want rather than managing the little details.

See the [Getting Started](getting-started) guide to start using fish.

### Why choose fish?
* **Networking** is handled seamlessly within modules, allowing you to simply write functions and have the client be able to call them instantly.
* **Cross module communication** allows you to write public variables or functions that can be accessed by any other module requiring it.
* **Intellisense** knows everything and is able to understand everything about a service or controller, allowing you to autocomplete anything.
* **Full type support** for everything, including client-server communication with [Promises](https://eryn.io/roblox-lua-promise/api/Promise).
* **Structuring** is unreasonably simple and allows you to manage your game easily with little conflict.
* **Features** you didn't even knew you needed are integrated by default such as [Mutex](https://en.wikipedia.org/wiki/Mutual_exclusion) or AdvancedLogger (in the future).
